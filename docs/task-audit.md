# Проверка задания

Исходные файлы находятся в `voice_router_dataset` и сохранены без изменений. Дата симуляции 1 октября 2026 года.

| Неясность или противоречие | Решение MVP |
| --- | --- |
| Основная рубрика даёт 100 баллов, отдельная голосовая оценка описывает 30 и 2 бонусных | Не складывать их в обещанный итог. Показывать доказательства по обеим шкалам |
| Образцы спрашивают несколько полей сразу; правила требуют один вопрос | Запрашивать одно недостающее поле |
| Примеры повторяют персональные данные целиком | Маскировать повторение и экранные сообщения |
| Действия каталога не всегда перечисляют все параметры изменения | Проверять дополнительные параметры по схеме полей и сценарию |
| SC02 не требует регион и тип машины, но расчёт цены использует их | Уточнять недостающие значения до предложения покупки |
| Для КАСКО разрешён возраст, для которого отсутствует ставка | Не рассчитывать неизвестный тариф; передать оператору |
| Каталог клиник не содержит доступных временных слотов | Явно обозначенное расписание симулятора; не выдавать за реальную запись |
| Полис виновника в SC12 принадлежит другому человеку | Ограниченный поиск полиса для регистрации потерпевшего; обычные изменения чужого полиса запрещены |
| ДМС включает услуги с направлением, но отдельного подтверждённого признака направления нет | Не оформлять такую запись автоматически, сообщать о необходимом направлении |
| Подтверждение в образце может содержать новый вопрос | Требовать отдельное однозначное подтверждение; новый вопрос сохранять в сценариях |
| Образцы диалогов задают точные ответы бота и следующие за ними «да» | Прогонять реальные ответы, отдельно учитывать несовпадения продолжений. Не подменять приложение эталонными ответами |
| Поиск клиента по телефону выглядит как авторизация | Разрешён только в учебной базе. Для реальной страховой нужны проверка личности и согласия |

Короткий путь к демонстрации проходит через четыре цепочки: ответ из знаний, расчёт с подтверждением, сохранение после обрыва и передача сотруднику. Они показывают функции и технические ограничения на одном наборе данных. Каталог сценариев и отчёт проверки дают проверяющему возможность воспроизвести результат.

Не входит в MVP: реальная телефония и исходящие звонки, настоящее бронирование, промышленная проверка личности, английский голос, обучение модели, векторная база и несколько экземпляров каждого сервиса.
