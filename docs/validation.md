# Проверка MVP, 23 сентября 2026

## Что подтверждено

- `pnpm typecheck` и `pnpm build` проходят.
- 12 автоматических тестов проходят. Они проверяют подтверждение изменённых параметров, повтор операции, обрыв до выполнения, перезапуск SQLite, переход к другому оператору, поиск истории нового клиента, формулы и одинаковые ключи переводов.
- 104 реплики проверены через OpenAI Realtime. 103 полных совпадения набора сценариев, 103 совпадения первого сценария. Итоговый прогон завершился без технических ошибок. Это результат на предоставленном dev-наборе, не оценка на неизвестных данных.
- 10 образцов диалогов, 40 клиентских ходов прошли через реальный маршрутизатор, Engine, SQLite и генерацию ответа. 39 из 40 наборов сценариев совпали. Ответы из образцов не подставлялись вместо реальных ответов.
- Три параллельных HTTP-сессии получили независимые истории и ответы. Проверены отказ при подмене полей подтверждения и роли, запрет чужого возобновления, закрытый служебный API, одновременное принятие обращения, передача и прекращение AI-ответов.
- Русская, казахская и смешанная синтезированные аудиофразы прошли через WebSocket приложения, живой Realtime, бизнес-правила и озвучивание. Все три дали SC33 и корректную транскрипцию. До первого звукового фрагмента на стороне тестового клиента: 5009, 4977 и 4387 мс соответственно. Это не измерение момента слышимого воспроизведения в браузере.
- В браузере проверены клиентский экран, смена RU/KK/EN с сохранением исходных реплик и ширины 1280 и 390 пикселей. Проверка после перезапуска сохранила историю и показала причину разрыва.
- Compose принимает конфигурацию. Секреты и локальная база исключены из Git. Graphify обновляет граф исходников; проверка путей не нашла секретов, истории, зависимостей или сборки.
- Русские тексты README и словарей проверены humanizer-ru. Линтер не нашёл жёстких нарушений. Слепая проверка README выявила три точечные правки, они внесены. Повторы в независимых названиях сценариев сохранены ради единообразия.

## Что ещё не подтверждено

Docker Desktop не смог запустить Engine в текущем окружении. Поэтому сборка образа, чистый `docker compose up --build` и сохранение volume между контейнерными перезапусками пока не проверены. Локальный запуск трёх сервисов через `pnpm dev` работает; перезапуск SQLite проверен отдельно.

Живой человек с микрофоном ещё не участвовал в приёмке. Синтезированные фразы проверяют проводку звука и модели, но не акценты, шум, перебивания и свободную речь. Автоматический VAD не используется: клиент завершает реплику кнопкой.

В U090 модель выбрала только SC18 вместо нескольких ожидаемых сценариев. В D09 последняя короткая реплика продолжила тему мошенничества вместо проверки полиса. В реальном прогоне предшествующий ответ отличался от образца, поэтому продолжение требует отдельной проверки диалога человеком. Неизвестные данные и неподтверждённые операции при этом не выполнялись автоматически.

Автоматические проверки атак охватывают несколько конкретных примеров на трёх языках и серверные ограничения. Они не доказывают устойчивость ко всем возможным атакам на модель. Сервис рассчитан на синтетические данные и одну копию каждого процесса.

Точные итоги и хеш инструкции маршрутизатора находятся в `validation-results.json`. Сырые локальные отчёты лежат в исключённой из Git папке `evals/artifacts`.
